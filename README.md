# 🍕🤡 DOM'S PIZZA PARLOR 🤡🍕

> THE MOST CHAOTIC PIZZA COMMUNITY ON THE INTERNET!

## What is this?!

DOM'S PIZZA PARLOR is a loud, chaotic, humor-driven website that serves as a pizza-parlour blog/community hub. Users can:

- 📝 **Post** about their favorite pizza shops
- ⭐ **Rate** weird toppings
- 💬 **Comment** on each other's entries
- 🤪 **Enable MAX CRINGE MODE** for extra chaos!

## Features

### 🤡 DOM the Mascot
A big, over-the-top, absurd cartoon clown character who represents the site's chaotic vibe!

### 📰 Blog Feed
Full-featured blog with:
- Posts with pizza ratings (out of 5 slices!)
- Weird topping highlights
- Comments system
- Filtering and sorting options

### 😂 Parody Ad Popups
Intentionally annoying fake ad popups that parody scammy banners from old web culture. **All clearly marked as jokes** - no real tracking or malicious behavior!

### 🎨 Retro "Cringe" Theme
Toggle the MAX CRINGE mode for:
- Extra animations
- Rainbow effects
- Maximum chaos!

### 👑 Admin Tools
Simple admin functionality to delete posts (password: `pizza123`)

## Tech Stack

- **React 19** - Modern UI framework
- **Vite** - Fast build tool
- **CSS3** - Custom animations and chaotic styling
- **localStorage** - Data persistence

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
